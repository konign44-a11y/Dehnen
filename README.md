# Dehnen & Mobility

Kleine Web-App (PWA) für meine tägliche Dehn- und Mobility-Session.

- Übungen laufen automatisch nacheinander, mit Timer, Tönen und Seitenwechsel-Hinweis
- Pause / Stopp / Überspringen jederzeit
- Monatsübersicht (aktueller + letzter Monat) der Tage, an denen gedehnt wurde
- Auf dem iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“
